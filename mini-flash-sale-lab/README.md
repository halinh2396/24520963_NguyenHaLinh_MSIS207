# HW1: Accessible Product Data-Grid

## Project
Mini Flash Sale Lab

## Objective
Build an accessible product data grid with sorting, filtering, pagination and keyboard navigation.

## Technologies
- React
- TypeScript
- HTML
- CSS
- Git and GitHub

## Features
- Product table with semantic HTML
- Sorting by product name, price and stock
- Product filtering
- Pagination
- Row selection
- Arrow-key navigation
- Enter and Space keyboard actions
- Accessibility labels and visible focus
- Responsive layout

## Installation

```bash
npm install
npm run dev
```

## Validation

```bash
npx tsc --noEmit
npm run build
```
